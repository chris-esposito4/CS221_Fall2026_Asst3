The assignment has 2 parts:

Write a C program that conforms to the C style guidelines as discussed in class. This program should do the following:
Part 1:
     Prompt the user to enter a string, up to some length you decide on.
    Print the string to output along with its length.
    For each character in the string, print
a)	the index into the string
b)	the character at that index
c)	the decimal value of the character
d)	the binary value (the 8 bit pattern) of 1s and 0s for that character

Part 2:
a)	Prompt the user to enter a string that consists of 8 0s and 1s in any order.
b)	Prompt the user to enter the decimal value that is the equivalent of the above pattern as a binary number.
c)	For an unsigned integer variable that is initialized to zero, modify its value by using bit operations so that its value reflects the bit pattern. The rightmost 0 or 1 in the entered bit string should correspond to the lowest order (1’s place) bit in the unsigned integer.
d)	Print the value the user entered in step (b) and the value you have created in step (c). Subtract one value from the other and print the result. If the result is not 0, explain why.

e)	Write and call a function that takes a floating point number as an argument. In separate outputs,
i)	Extract the sign bit and print if the number is positive or negative
ii)	Extract the exponent and print it
iii)	Extract the mantissa and print it
